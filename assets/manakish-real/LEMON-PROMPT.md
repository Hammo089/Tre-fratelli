# Lemon squeeze asset

Built-in imagegen, transparent alpha, optimized to WebP512. Used as a transient moving squeeze effect with juice droplets; never scattered onto the dough.

Use case: product-mockup. Transparent photographic cutout for a web animation of lemon squeezing above Lebanese manoushe. One fresh yellow lemon half, viewed from slightly above and the front side, juicy pale yellow cut flesh facing diagonally down toward viewer, thick textured yellow rind at upper back, realistic moist citrus segments. Centered isolated single object occupies 75% of square frame, no hands, no board, no shadows outside lemon, no props, no text. Crisp high-end real food photography. Fully transparent background. No juice drops yet; these will be animated by code.
